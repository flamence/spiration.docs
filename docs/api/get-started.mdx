# 入门

Spiration 拓展之旅的第一步，不妨来创建一个独属于你的 Hello World 拓展。
请确保你已安装 [CMake](https://cmake.org/) 与任意可用的 C 工具链
（clang、gcc、MSVC 均可）。

## 选择拓展形态

| 形态 | 入口 | 适用场景 |
|---|---|---|
| **纯 C** | 导出 `spiration_extension_entry` | 追求极致稳定与跨编译器兼容 |
| **C++** | 同上，另可用 `spiration/api.hpp` 便利封装 | 需要与宿主共同开发、复用 C++ |
| **C++（原生对象）** | 导出 `spiration_initialize`，返回 `spiration::extension*` | 既有 C++ 拓展；宿主会传入 `host` 与描述符 |
| **Python** | `extension.json` 声明 `"loader": "com.flamence.spiration.python"` | 快速迭代、调用 Python 生态 |
| **Node.js** | `extension.json` 声明 `"loader": "com.flamence.spiration.node"` | 调用 npm 生态 |

前两种只交换 C 结构，是新拓展的推荐做法；`spiration_initialize` 供需要以 C++
对象（虚函数生命周期）实现的拓展使用，它在**装载期**即可拿到按本拓展特异化的
`host` 与描述符——详见
[设计规范 · C++ 入口的 host 参数](design.mdx#c-入口的-host-参数)。

本页以**纯 C** 为例，因为它最少依赖、最能体现 C API 的约定。

## 创建拓展

我们推荐通过项目生成器来初始化项目：

<ProjectGenerator />

假定直接按照预设的拓展配置生成项目，
看到 `/hello-world/src/main.cpp`，
我们来编写一个简单的日志输出：

```cpp
static spiration_bool SPIRATION_CALL on_initialize(spiration_extension_desc* self) {
    self->host->log(self, SPIRATION_LOG_INFO, SPIRATION_STR("hello, world"),
                    SPIRATION_STR_EMPTY);
    return SPIRATION_TRUE;
}
```

## 调试拓展

借助 CMake，我们能够直接启动 Spiration 来调试我们的拓展。
现在，请你尝试运行你的拓展。

如果你看到了 `hello, world` 的日志，
恭喜你！你成功创建了你的第一个拓展！

## 打包拓展

同样的，使用 CMake 进行 `package` 操作，
即可得到拓展压缩包并分发给用户了。
