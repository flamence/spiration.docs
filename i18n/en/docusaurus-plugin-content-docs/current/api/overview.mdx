# Overview

Spiration has certain extension capabilities that can greatly enhance the user experience for all types of users.
This section aims to introduce the Spiration extension system and related development.

## How to create an extension?

We recommend that you learn through various classic extension projects and related documentation:

- Start with the [Getting Started](get-started.mdx) guide to create your first extension step by step.
- Refer to the already very detailed API reference documentation, [Spiration API](spiration-api.mdx).
