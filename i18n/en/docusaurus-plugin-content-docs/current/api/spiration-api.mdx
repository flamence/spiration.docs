# Spiration API

**Spiration API** is a set of fields and methods that you can call within a Spiration extension.
It is not limited to compiled languages like C/C++ for dynamic library loading;
with a suitable extension loader, extensions written in other languages can also be loaded.
The API list provided on this page is referenced from the Doxygen comments in [extension.h](https://github.com/flamence/spiration/blob/main/common/include/extension/extension_api.h).

The Spiration API is generally accessed through the `api` field provided inside `spiration::extension`.
