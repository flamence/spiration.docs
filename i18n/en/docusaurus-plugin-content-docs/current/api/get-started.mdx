# Getting Started

The first step in your Spiration extension journey is to create your very own Hello World extension.
Make sure you have [CMake](https://cmake.org/), [clang](https://clang.llvm.org/), or another available toolchain installed.

## Creating an Extension

Create a folder, for example `hello-world`.
Then, inside the folder, create `CMakeLists.txt` to configure the project.

<details>
<summary>/CMakeLists.txt</summary>

```cmake
cmake_minimum_required(VERSION 3.14)
project(hello-world VERSION 0.1 LANGUAGES C CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

include(FetchContent)
FetchContent_Declare(
    spiration
    GIT_REPOSITORY https://github.com/flamence/spiration.git
    GIT_TAG main
)
FetchContent_Populate(spiration)

file(GLOB_RECURSE EXTENSION_SOURCES
    "src/*.cpp"
    "src/*.c"
)
file(GLOB_RECURSE EXTENSION_HEADERS
    "include/*.h"
    "include/*.hpp"
)

add_library(${PROJECT_NAME} SHARED ${EXTENSION_HEADERS} ${EXTENSION_SOURCES})

target_include_directories(${PROJECT_NAME} PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/include
)

target_link_libraries(${PROJECT_NAME}
    spiration::api
    llama
)

set_target_properties(${PROJECT_NAME} PROPERTIES
    RUNTIME_OUTPUT_DIRECTORY ${CMAKE_CURRENT_BINARY_DIR}/bin
    LIBRARY_OUTPUT_DIRECTORY ${CMAKE_CURRENT_BINARY_DIR}/lib
    ARCHIVE_OUTPUT_DIRECTORY ${CMAKE_CURRENT_BINARY_DIR}/lib
)

install(TARGETS ${PROJECT_NAME}
    LIBRARY DESTINATION "lib"
)

install(DIRECTORY res/
    DESTINATION "resources"
)

```

</details>

Create the following files/folders in order: `include/hello-world.hpp`, `res/extension.json`, `src/hello-world.cpp`.
Let's first configure extension.json.

<details>
<summary>/res/extension.json</summary>

```json
{
    "id": "com.example.hello-world",
    "name": "Hello World",
    "version": "0.1",
    "main": "libhelloworld.so",
    "api_version": 0
}

```

</details>

Next, let's write the extension code:

<details>
<summary>/include/hello-world.hpp</summary>

```cpp
#pragma once

#include <extension/extension.h>

class hello_world : public spiration::extension {
public:
    bool initialize() override;
    void shutdown() override;
    init_phase phase() const override { return init_phase::normal; }
    std::string id() const override { return "com.example.hello-world"; }
    std::string name() const override { return "Hello World"; }
    std::string version() const override { return "0.1"; }
    std::string description() const override { return "My first Hello World extension."; }
};

```

</details>

<details>
<summary>/include/hello-world.cpp</summary>

```cpp
#include <hello-world.hpp>

#ifdef _WIN32
    #define EXPORT __declspec(dllexport)
#else
    #define EXPORT __attribute__((visibility("default")))
#endif

bool hello_world::initialize() {
    api->log_info("Hello World!");
    return true;
}

void hello_world::shutdown() {
    api->log_info("Goodbye!");
}

extern "C" {
    EXPORT spiration::extension* create_extension() {
        return new hello_world();
    }
}

```

</details>

## Debugging the Extension

With CMake, we can directly launch Spiration to debug our extension.
Now, try running your extension.

If you see the log message `Hello World!`,
congratulations! You have successfully created your first extension!

## Packaging the Extension

Similarly, use CMake to perform the package operation,
and you will get a compressed extension package to distribute to users.
